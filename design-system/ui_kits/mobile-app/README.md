# CHIMERA mobile app — concept kit
Companion app for innovation managers in the field: quick idea capture (text/voice), project status, compatible bandi, assistant. Three interactive devices; tab bar switches screens.
Mobile rules: hit targets ≥ `--tap-min` (44px), body 15px, cards use `--radius-lg` (10px), Buttons `size="lg" fullWidth`, tab-bar icons 24px. Same tokens, same components as web.
This is a **concept** — no mobile app exists yet.
